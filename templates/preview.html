3. Rapid Technical Q&A Prep (Python, Flask, Django, React)

Q: Flask vs. Django - What is the difference?
Django is a "batteries-included" framework with built-in ORM, admin panel, auth, and form handling—ideal for monolithic enterprise apps. Flask is a lightweight micro-framework giving developers complete freedom to pick libraries—ideal for microservices, lightweight APIs, and ML model serving.
Q: What is the Python GIL (Global Interpreter Lock)?
The GIL is a mutex in CPython that ensures only one native thread executes Python bytecode at a time. For I/O-bound tasks (web requests, database calls), threads release the GIL. For CPU-bound tasks, we use the `multiprocessing` module to utilize multiple CPU cores.
Q: What are React Hooks (`useState`, `useEffect`)?
Hooks allow functional components to manage local state and lifecycle side effects. `useState` stores component state across re-renders; `useEffect` runs asynchronous side-effects (such as API data fetching or event listeners) when specified dependencies change.
Q: What are MySQL Joins & Indexes?
Joins combine rows from two tables: INNER JOIN returns rows with matching keys in both; LEFT JOIN returns all rows from the left table and matched rows from the right. Indexes (B-Trees) accelerate query search times from O(N) linear scans to O(log N) lookups.
